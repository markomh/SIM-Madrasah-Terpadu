## E2E AUDITABILITY VERIFICATION STRATEGY

Setiap entri **Application Contract Graph** di atas dapat diaudit secara otomatis oleh Tim QA melalui rute berikut:
1. **Backend Integration Level**: PHPUnit Feature tests (`php artisan test`) menguji setiap pasangan **HTTP Method + Endpoint + Guard + Expected HTTP Status**.
2. **Frontend UI Level**: Menubuilder `app-shell.tsx` & `layout.tsx` Route Guard menguji ketersediaan tombol/rute berdasarkan capability object `getCapabilityFlags()`.
3. **Multi-Tenant Scoping Level**: `BelongsToTenant` Eloquent Global Scope & PostgreSQL RLS memastikan percobaan *Cross-Tenant* atau *Cross-Row Reference* mengembalikan **HTTP 404 Not Found** (bukan HTTP 403 atau 200).
